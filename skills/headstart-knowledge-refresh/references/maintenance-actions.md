# Knowledge Maintenance Actions

## Keep

Use when the artifact remains accurate, useful, appropriately located, and sufficiently discoverable.
No edit is required.

## Update

Use when the artifact still owns the topic but contains stale facts, broken links, unclear wording,
missing limitations, or volatile state that should be replaced by a live reference.

## Consolidate

Use when two artifacts answer substantially the same retrieval question and separate maintenance
creates more drift risk than retrieval value. Name the canonical survivor, the unique material to
preserve, all inbound links to repair, and the disposition of the redundant artifact.

Do not consolidate merely because two pages mention the same system or project.

## Replace

Use when the current guidance is materially misleading and a trustworthy successor with a clearer
contract can be written. Preserve useful history or decision context and identify the successor link.

## Retire

Use only when the problem domain is gone, the content is fully superseded with no unique value, or
the artifact is demonstrably redundant. Identify inbound references and verify that the canonical
survivor contains the necessary guidance.

## Unverified

Use when available sources cannot establish whether a claim remains true. Unverified does not mean
false. State the missing evidence, likely owner, and whether the gap affects current decisions.

## Move

Treat relocation as an update. Recommend it only when ownership or taxonomy is clearly wrong and the
target already has a defensible role. Repair inbound links when applying an approved move.

## Maintenance Report Row

For each artifact provide:

List `Keep` items as reviewed without edits so coverage is explicit.
