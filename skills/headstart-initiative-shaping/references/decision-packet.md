# Decision Packet

Use the following sections when they add decision value. Omit empty sections rather than filling them
with generic prose.

## Initiative Summary

- Desired outcome
- Current pain and affected people
- Why the work matters now
- Current phase and immediate deliverable

## Scope

- Inputs
- Outputs
- In scope
- Non-goals
- Human review or approval boundary
- Success measures

## Current Understanding

Use stable IDs and concise evidence citations.

| ID   | Statement          | Status     | Evidence               | Confidence |
| ---- | ------------------ | ---------- | ---------------------- | ---------- |
| F-01 | Supported fact     | confirmed  | Source ID and location | high       |
| A-01 | Working assumption | assumption | Basis, if any          | low        |

Allowed status values are `confirmed`, `inferred`, `assumption`, and `conflicting`.

## Decision Register

| ID  | Decision | Current direction | Owner | Needed by | Downstream impact |
| --- | -------- | ----------------- | ----- | --------- | ----------------- |

Use `D-##` for decisions. Do not mark a direction as approved without evidence of approval.

## Stakeholder Questions

For every `Q-##` include:

- current understanding;
- the exact confirmation or choice needed;
- who is best positioned to answer;
- where the answer should be recorded; and
- what remains blocked or changes based on the answer.

Ask interactively one at a time when the user is present. In a handoff document, list all questions
with explicit answer locations.

## Risks And Alternatives

Use `R-##` for material risks. Include likelihood only when evidence supports it. Distinguish
reversible choices from decisions that are costly to undo.

## Recommended Next Slice

Name the smallest useful next deliverable, its prerequisites, completion evidence, and what it does
not attempt.

## Source Register

| Source ID | System | Title or identifier | Date/version | Role | Notes |
| --------- | ------ | ------------------- | ------------ | ---- | ----- |

Link to authorized sources when the output surface supports links. Do not expose private download
URLs, credentials, raw file bytes, or unnecessary sensitive content.
