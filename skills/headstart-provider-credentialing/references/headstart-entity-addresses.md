## Keep roles, conflicts and changes explicit

- Distinguish the enrolling Headstart legal entity and practice address from the provider's
  business/registered-agent addresses and from actual service, mailing, correspondence and pay-to
  roles. A selected case address or a service-modality checkbox is not a payer-address mapping.
  Preserve source facts; never overwrite a provider's address with Headstart's to make them agree.
- Cite the current workbook values **and** the dated Ops clarification where selection depends
  on it. Explain which payer field/role is supported and why. Reuse the host's existing evidence,
  answer and investigation contracts; do not invent fields or mark a source inspected solely
  because this reference names it. The clarification is attributed context, not a newly retained
  Slack original or a current read of its replies.
- If workbook labels, newer authorized Ops guidance or payer requirements conflict with the dated
  rule, investigate their scope and authority. A newer file is not automatically controlling.
  Adopt an explicit, applicable supersession when supported; otherwise preserve both sources,
  leave only affected answers unresolved and ask Ops for the precise decision. Continue independent
  preparation. Never waive payer requirements using internal guidance or treat missing cells as
  proof that no valid address exists.
- A workbook update requires reassessing affected roles/selections and publishing a new complete
  package with renewed review when material. Retain prior source versions, packages and approval
  history. Do not silently rewrite earlier packages or reuse approval for changed addresses.
- If the workbook cannot be read, use other authorized current evidence where sufficient and name
  the exact unresolved source/role. Do not widen sharing, switch to an employee identity, fabricate
  values or ask Ops to retype already-readable information. No payer or source write follows.
