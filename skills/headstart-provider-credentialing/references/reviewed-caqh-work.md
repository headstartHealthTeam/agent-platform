# Reviewed CAQH profile work

Use this guidance when the operator shares a CAQH profile and releases a reviewed package. The operator signs in privately. Check the individual provider's name, individual NPI and the Headstart practice against the released case before touching any record. Return control if the profile cannot be identified.

For a first-time Headstart entry, search the existing locations, employers and contacts before adding one. For an existing entry, update only the reviewed Headstart fields. Preserve unrelated employers and their contact information. Ask the provider through the operator about uncertain employment, discrepancies that supporting records cannot resolve, or a proposed removal. Use the maintained tracker for the selected address purpose, state and destination. Georgia CAQH uses the main Georgia practice address. A nearest-MSA payer rule applies to that payer enrollment only.

Use a saved, reviewed document with its exact revision. Upload the verified combined liability cover and current certificate where required. Inspect the portal's document list after upload. A selected filename in the input is insufficient. For a saved field, leave and reopen the relevant section and compare the persisted value to the reviewed value. Record the section, requirement and visible confirmation. A timed-out save or upload requires this same readback before any retry. Where persistence is ambiguous, return to private operator control to verify it.

The operator completes final attestation, signing and payer submission. The operator records the actual completed date after seeing CAQH's confirmation, then reviews the corresponding Salesforce provider and date before authorizing the single-field update.
